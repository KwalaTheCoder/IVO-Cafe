# IVO CAFÉ — بسته کامل فرانت‌اند و بک‌اند

این فایل ZIP شامل فرانت‌اند و بک‌اند منوی دیجیتال **IVO CAFÉ** با حال‌وهوای سفالی و رنگ‌های قهوه‌ای گرم، آبی ملایم، صورتی کمرنگ و سبز یشمی است.

## ساختار پوشه‌ها
- `frontend/index.html` — ساختار صفحه منو
- `frontend/style.css` — استایل سفالی و ریسپانسیو با آیکون‌های SVG
- `frontend/script.js` — جستجو، فیلتر دسته‌ها، بزرگ‌نمایی تصویر، ویرایش زنده و اتصال به API
- `frontend/assets/` — محل قرارگیری عکس‌های منو (`product-1.svg` / `product-2.svg` / `product-3.svg` یا عکس‌های واقعی خودتان)
- `backend/server.js` — سرور Node.js برای سرو فرانت‌اند و API (`GET /api/menu` و `PUT /api/menu`)
- `backend/data/menu.json` — دیتای منوی کافه ایوو
- `package.json` — تنظیمات اجرای پروژه

## نحوه اجرا و تبدیل (از حالت استاتیک به بک‌اند یا اجرای کامل)

### ۱. استخراج فایل ZIP
فایل ZIP را از حالت فشرده خارج کنید تا پوشه `ivo-cafe-fullstack` ایجاد شود.

### ۲. اجرای پروژه با بک‌اند (Node.js)
1. [Node.js](https://nodejs.org) را نصب کنید.
2. ترمینال را در پوشه `ivo-cafe-fullstack` باز کنید و دستور زیر را بزنید:
   ```bash
   npm start
   ```
3. مرورگر را باز کنید و به آدرس `http://localhost:3000` بروید.
4. با زدن دکمه **ویرایش** و سپس **ذخیره در بک‌اند**، تغییرات مستقیماً در `backend/data/menu.json` ذخیره می‌شوند.

### ۳. استفاده فقط به صورت فرانت‌اند استاتیک (بدون بک‌اند)
اگر بخواهید بدون سرور بک‌اند (مثلاً روی GitHub Pages یا Netlify) استفاده کنید:
- پوشه `frontend` را آپلود کنید.
- در این حالت ویرایش متن‌ها در مرورگر (`localStorage`) ذخیره می‌شود و بدون نیاز به سرور کار می‌کند.
